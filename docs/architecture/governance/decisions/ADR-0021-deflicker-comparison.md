# ADR-0021 — Explicit short deflicker comparison

Proposed for #106, not ratified by source inclusion. Temporal smoothing can
remove intentional animation/lighting choices. Require a separately selected,
bounded original-clock excerpt and closed filter/settings with before/after
frames, exact source-time mapping and a silent local comparison view. Retain
ordinary native v3 process/cancellation/checkpoint/acceptance authority. Native
integrity/decode observations cannot establish perceptual improvement.

An omitted configuration is an inspectable saved bypass needing no tool/model.
A supplied immutable review binds the actual comparison/context, not the full
video, final codec or original audio. This preview cannot silently become a
production restoration stage, full creative approval or publication grant.
Source/master bytes, other processing order and final export stay in their
existing owners. No arbitrary DAG, model runtime or second acceptance database
is introduced. Native/visual/platform qualification remains in the final pass.

Broader restoration/color management, continuous full-video application, native
performance and real visual decisions require separate evidence and review.
