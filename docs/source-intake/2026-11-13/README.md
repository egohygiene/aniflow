# Original trial scripts

These 7 scripts were supplied by the maintainer from the Drive scripts folder and preserved byte-for-byte for aniflow issue intake on 2026-11-13.

They remain trial/reference sources. Preservation does not adopt their defaults, establish correctness or licensing of dependencies, or install or execute anything. Future work should reuse the repository's existing owners and record which behavior is already covered, adapted or retained only as reference.

The originals retain their exact names and contents. The archive stores them without executable mode. See [manifest.json](manifest.json) for original sizes and SHA-256 hashes. Download individual files from their immutable commit links in the intake issues.

Keep the archive branch while those issues depend on these files; their Drive copies are being removed only after GitHub readback is verified.
