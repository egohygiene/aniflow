# Managed RIFE runtime identity

RIFE remains an explicitly selected, serial midpoint interpolation stage. Tool
acquisition does not enable interpolation. The managed catalog selects the
official 20221029 distribution and its `rife-v4.6` model pair; older multi-network
model directories are not interchangeable with this fixed profile.

`RifeSettings.managed_runtime` retains the package digest, catalog revision and
declared runtime files. The ordinary provider copies those files beside its
private executable, verifies the closed membership and hashes before and after
native midpoint calls, and includes their bytes in admission and component
observation. Package changes alter exact effective configuration and invalidate
stale checkpoint compatibility. An empty closure still retains package identity;
it means this distribution has no non-system companion libraries to stage.

Managed store/installation roots are protected from output writes. Fresh managed
normal and preview runs retain their exact configuration at the durable run
boundary. Read-only `retained_configuration` helpers compare these convenience
copies against the immutable plan's effective provider lock before returning
them. Resume uses those original pins, without selecting current defaults or
downloading a new version. A failed convenience-copy write cancels processing;
the copy never replaces native checkpoint acceptance.

Omitting this field preserves historical explicit configurations and their
serialized identities. Historical schema files are unchanged. Managed effective
provider and preview/recovered/spatial wrappers use separate schema references.

Official Mac binaries were inspected for load commands; this does not establish
native execution, GPU driver availability, memory use or visual quality. Their
remaining native qualification gates are documented in the sprint PRs.
